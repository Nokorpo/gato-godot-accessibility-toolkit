Description

A simple checkbox that allows inverting the vertical direction of the joystick. If checked, it is inverted. If it isn’t checked, it’s the default orientation.

Method Descriptions

void update_ui(input_action: JoystickInputAction2D) 🔗

Reacts to the GatoInputRemapper.control_scheme_changed signal to populate the UI with the loaded control scheme and propagates it down to its descendants so they can do the same.
