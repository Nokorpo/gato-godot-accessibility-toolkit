.. rst-class:: classref-introduction-group

Description
-----------

This class loads and stores control schemes and input configuration defined in InputRemapper. It stores all data in "user://input.data" by default.



The format is a mix of custom JSON and Godot's native to json conversion (for more information, see `this link <https://docs.godotengine.org/en/stable/classes/class_json.html#class-json-method-from-native>`__).
