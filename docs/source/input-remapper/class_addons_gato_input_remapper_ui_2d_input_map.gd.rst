.. rst-class:: classref-introduction-group

Description
-----------

A Control that let's the user choose whether to use a joystick (JoystickInputAction2D) or keys/controller buttons (KeysInputAction2D) for an input action 2D. It also allows configuring the joystick or keys/buttons used for this input.
