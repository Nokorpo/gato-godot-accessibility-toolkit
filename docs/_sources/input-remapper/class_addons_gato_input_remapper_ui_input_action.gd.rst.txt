.. rst-class:: classref-introduction-group

Description
-----------

Control node that represents an `InputAction` as a `Label` and `Button`. The `Label` shows the `InputAction`'s name, while the `Button` shows its triggering key or button.  The `Button` also allows re-configuring the triggering key or button by pressing on it. A dialog that listens to key presses should show up when clicking on it.
