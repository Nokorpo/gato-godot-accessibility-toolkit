Description
-----------

This class is a Resource that represents a voice in the OS's Text-to-Speech API. We try to provide defaults so that developers using this addon don't have to waddle through lists of dozens or hundreds of voices to select defaults for their game.  The list of curated voices can be found in `res://addons/gato_tts/ui/resources/` under the names `windows.tres`, `linux.tres`.
