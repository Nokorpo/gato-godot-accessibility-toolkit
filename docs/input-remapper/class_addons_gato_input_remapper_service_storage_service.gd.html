Description

This class loads and stores control schemes and input configuration defined in InputRemapper. It stores all data in “user://input.data” by default.

The format is a mix of custom JSON and Godot’s native to json conversion (for more information, see this link).

Property Descriptions

String settings_file = "user://input.data" 🔗

Defines where the settings will be stored once changes are saved. This is also the path that will be used to reload the settings next time the game runs.

Script control_scheme_script = load(...) 🔗

Reference to the control scheme class script. Used to create new GatoControlScheme instances when loading the configuration from the input.data file.

Method Descriptions

Error verify_config_file(file_path: Variant = null) 🔗

Checks that the configuration file can be loaded correctly. If the file doesn’t exist, cannot be parsed into JSON or the reading results in an empty list of control schemes, it returns an error.

void initialized_file_with_input_map(file_path: Variant = null) 🔗

If the settings file is not found, it needs to be generated for the plugin to work. This method generated the settings file with the Input Map defined in the project.

Array[GatoControlScheme] load_input_config_from_file(file_path: Variant = null) 🔗

Loads the input map configuration from a file. If no argument is passed, it will load the configuration from “user://input.data”.

Array[GatoControlScheme] load_input_config_from_json(json: Dictionary) 🔗

Loads the input map configuration from a json dictionary.

void store_input_config(input_config: Variant, file_path: Variant = null) 🔗

Stores the control schemes modified by the user in a file. If no argument for the file is passed, it will store the configuration in “user://input.data”.
